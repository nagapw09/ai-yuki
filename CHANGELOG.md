# Изменения

Формат — по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [семантическому версионированию](https://semver.org/lang/ru/).

Этот файл читают двое: человек, решающий, стоит ли обновляться, и клиент
обновления, который показывает эти строки в окне. Поэтому здесь то, что меняется
для пользователя, а не список коммитов.

## [Не выпущено]

### Добавлено

- **Мастер первого запуска**: язык, выбор модели с проверкой подключения,
  пошаговая выдача разрешений и сверка с системными требованиями. На macOS
  статус Accessibility и Screen Recording спрашивается у системы, а не
  предполагается.
- **Фоновый режим**: иконка в трее с состоянием Yuki, закрытие окна в трей,
  автозапуск вместе с системой, режим «поверх остальных окон».
- **Обновления**: проверка и установка из настроек, сборка выпусков для Windows
  и обеих архитектур macOS. Канал включается ключом подписи — см.
  `docs/RELEASE.md`.
- **Системные требования** (`docs/REQUIREMENTS.md`) и их живая сверка с машиной.
- **Календари** Google Calendar и Outlook: просмотр, создание и удаление
  событий (ТЗ §25).
- **Плагины** (ТЗ §20): манифест, установка из папки, git-репозитория или
  созданная самой Yuki заготовка, permission review до запуска.
- **Local Only** (ТЗ §29): режим, в котором ни реплики, ни записи голоса не
  уходят с машины.
- **Аватар** (ТЗ §12): отдельное прозрачное окно поверх остальных, восемь
  состояний, мимика, click-through.
- **Семантический поиск по памяти** поверх текстового (ТЗ §9).
- Снимок экрана научился области и уменьшению — на порядок меньше данных
  в каждом шаге агента (ТЗ §6).

## [0.1.0]

Первая внутренняя сборка: агентный цикл, провайдеры моделей, голос, зрение,
память, разрешения, автоматизации, MCP и Capability Hub.
