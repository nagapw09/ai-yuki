## Сделано в 0.4.0

Голос и разговор:
- `ConversationWindow` (rust/voice/src/session.rs): 7 с после ответа Yuki
  фраза без имени считается обращённой. Открывается в `voice_speak`, закрывается
  в `voice_stop`.
- Быстрые команды без модели — `apps/desktop/src/agent/quick.ts` (идея Jarvis):
  открыть приложение/сайт, стоп, плеер, громкость, время, движения персонажа.
  Через тот же Permission Gate; незнакомое уходит модели.
- Короткие ответы по умолчанию и метка настроения `[радость]…` →
  выражение лица (`agent/reply.ts`). Текст для голоса без разметки.
- «Стоп» прерывает думающую Yuki; на одно имя она отвечает «Да?».

Персонаж:
- Наборы клипов на действие со случайным выбором, занятие «Позировать»
  (`avatar/motions.ts`).
- Слои поверх клипов в `avatar/scene.ts`: дыхание, голова за взглядом, кивки в
  речи, наклон в раздумье. Добавка снимается каждый кадр (`undoLayers`).
- Реакция на перетаскивание.

Интерфейс (макеты: https://claude.ai/artifact/93qvdFvUxu22KwJPoSWxDh):
- Навигация Astra в строке заголовка; `SectionPage` — страницы с подразделами;
  `screens/Pages.tsx` раскладывает старые блоки `Settings.tsx` по ИИ/Голос/Настройки.
- Главная, Команды, Персонаж переделаны по макету. Шрифт Onest локально.
