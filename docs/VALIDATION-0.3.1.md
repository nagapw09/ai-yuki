# Проверка Yuki 0.3.1 — 18 сентября 2026

## Изменения

Оригинальные текстуры возвращены по умолчанию; 1024px доступны через отдельный экономный режим. Полное разрешение экрана доDPR2 вместо общего ограничения1.25. Сохранены оптимизации skeleton/morph и освобождение кэша.

Авторские выражения выбраннойVRM доступны в интерфейсе. Это не импорт скачанных Unity .anim для другого лица. После ручного выражения восстанавливаются обычное моргание и остальные состояния.

Автономность выбирает только доступные клипы. Авторский showcase добавлен отдельным действием «Размяться», один проход. Его полный цикл содержит развороты/шаги: он не используется как бесконечный спокойный idle. Автономность не блокируется на120сек от клика по эмоции. На старте auto/stand начинает самостоятельный выбор через12сек.

## Осталось

Unity по-прежнему отклоняет конвертацию из-за отсутствия лицензии. Новые sit/walk/dance/idle из .anim не готовы. Нельзя выдавать текущую автономную разминку за завершение всех анимаций. Совместимость Shinano/リア-アリス требует подходящей модели или проверенного переноса. СборкаmacOS, полноценныйTelegram file-send и пользовательскийSTT не проверены.

Замер0.3.0 сLulum788MiB относится к уменьшенным1024текстурам, НЕ к оригинальному качеству0.3.1. Новый замер необходимо указывать отдельно.
