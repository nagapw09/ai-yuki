# Проверка Yuki 0.3.0

17 сентября 2026, Windows x64, нативный Tauri release + WebView2.

## Автоматические проверки

- `npm test`: 120 тестов — 38 desktop, 82 core, все прошли.
- `cargo test --workspace --offline --quiet`: 293 теста, все прошли.
- `npm run tauri:build -- --bundles nsis -- --offline`: TypeScript и production frontend собраны, release EXE и NSIS созданы.
- Регрессии: частичный ответ/ошибка после следующего сообщения, статусы инструментов, постоянный inbox напоминаний, CLI vision, выбор готовых клипов и VRM texture cache.

## Нативные сценарии

- В окончательном portable повторно проверено напоминание из трея: до срока окно скрыто, после срока visible=true, banner=true, persisted=true, пауза UI снята. Тестовая запись удалена. Создание новой команды из открытой библиотеки показывает редактор; ничего не сохранено/не запущено. Portable EXE совпадает по SHA256 с target/release.
- Настоящее напоминание через 8 секунд: запись в inbox и видимая карточка подтверждены. Тестовая запись удалена. Inbox сохраняется в SQLite и не зависит от успешности Windows toast.
- UI Automation прочитал собственное окно приложения, вернув 461 символ без RPC_E_CHANGED_MODE. COM объекты создаются на отдельном потоке; вызов не блокирует UI.
- Официальные Claude Code и Codex обработали синтетическое изображение со словом ORCHID и вернули VISION_OK. Использован существующий вход CLI. Пользовательские снимки экрана в тесте не отправлялись.
- Мышью передвинуты главное окно и окно аватара: +100 / −30 px, затем координаты восстановлены. Проверка ограничена видимыми окнами процесса Yuki.
- Главная отображает реальные системные CPU/GPU/RAM и диски. В Windows не задано DefaultGeoposition: предложено указать город.
- Проверены Miku, Lulum и новый RadDoll Short, полное кадрирование, мимика Lulum после оптимизации. Оба новых RadDoll доступны в профилях. Не все профили прошли все движения.
- Библиотека команд открывает шаблон на полотне. Во время QA шаблон не сохранялся и не запускался.

## Производительность

`scripts/measure-load.ps1` считает дерево процессов Yuki вместе с WebView2. CPU усреднён за 8 секунд и нормирован на все логические процессоры. Память — сумма Working Set, включая разделяемые страницы, не точный объём уникальной физической памяти.

| Состояние | CPU | Working Set | Private bytes |
|---|---:|---:|---:|
| Release без 3D, исходный замер | 0,78% | 454 MiB | 259 MiB |
| Release с Lulum до texture/morph оптимизации | 2,85% | 4981 MiB | 7047 MiB |
| Release с Lulum после оптимизации | 1,44% | 788 MiB | 790 MiB |

Одинаковая модель и ПК, короткие замеры отдельных запусков; это не длительный benchmark. Последний замер сделан до переключения между несколькими моделями; кэш держит один неактивный персонаж до 60 секунд.

Распакованные текстуры Lulum: 603 → 57 MiB. Исходный VRM не изменён; оптимизированная копия в AppData/avatar-cache. Используются ограничение текстур 1024, объединение совместимых skeleton/morph данных, ограничение кадров и пауза скрытого окна. Замеры GPU/VRAM, холодного старта и длительного переключения ещё нужны.

## Границы проверки

- Unity отказал без активной лицензии. 144 скачанных .anim подготовлены к конвертации, но новые танцы/сидение/ходьба ещё не выпущены. Самодельная хореография удалена; отсутствующие действия отключены.
- Telegram Desktop: устранены обнаруженные COM и CLI vision препятствия, но отправка файла в настоящую группу не проверена. Telegram Bot требует токен/сопряжение; полного end-to-end теста нет.
- Windows toast зависит от установки и системных настроек. Проверка in-app карточки не доказывает показ OS toast на чистой машине.
- Живой микрофон/STT пользователя не проверен. CLI не предоставляет ключ STT. Рот по громкости аудио — не фонемный lip-sync.
- macOS не собран и не проверен. Подпись, notarization и обновления не настроены. NSIS на чистой Windows ещё не устанавливался.
- История чата в localStorage пока не полностью входит в экспорт SQLite.
- Полный статус: [SPEC-STATUS.md](SPEC-STATUS.md). Старые заявления «всё закрыто» в исторических документах не являются приёмкой.
