# Первый запуск Yuki 0.2

## Windows

Установите `Yuki_0.2.0_x64-setup.exe` и запустите Yuki из меню «Пуск». Установка выполняется для текущего пользователя. Для portable-версии распакуйте архив и запустите `Yuki.exe`. Нужен Microsoft Edge WebView2 Runtime (обычно уже есть в Windows 11; установщик Yuki умеет установить его при наличии интернета).

Новая Yuki хранит данные отдельно от старого проекта: идентификатор `ai.yuki.companion`. Старую Yuki удалять не требуется. Не запускайте одновременно два приложения с одинаковой глобальной горячей клавишей.

## Вариант 1: API-ключ

1. В мастере выберите OpenAI, Claude, Gemini или другой сервис.
2. Вставьте ключ в поле пароля, проверьте подключение и укажите доступную модель. Ключ хранится в Credential Manager / Keychain.
3. Для голоса выберите распознавание: сохранённый ключ OpenAI или отдельный ключ OpenAI/Groq. Озвучка системным голосом не требует ключа.
4. Разрешите микрофон. Доступ к файлам, управлению интерфейсом и экрану нужен только соответствующим действиям.
5. Нажмите на ядро или микрофон и произнесите короткую фразу. Проверка подключения модели не заменяет проверку распознавания речи.

## Вариант 2: ваша подписка через CLI

Если Claude Code уже установлен и вы вошли в аккаунт, повторная установка не нужна. Иначе установите официальный CLI, затем войдите:

```text
npm install -g @anthropic-ai/claude-code
claude auth login
```

Для Codex:

```text
npm install -g @openai/codex
codex login
```

После установки CLI перезапустите Yuki. Выберите «Claude Code · подписка» или «Codex · подписка ChatGPT», нажмите «Проверить вход». `default` оставляет выбор модели CLI; для Claude также можно задать `sonnet`, `opus`, `haiku`, для Codex — доступный аккаунту ID модели.

Yuki не копирует OAuth-токены и не входит в аккаунт от вашего имени. Текст передаётся официальному CLI, который использует собственную авторизацию. Программные запросы расходуют доступные для них лимиты плана. Остаток лимита проверяется в CLI: Yuki не показывает выдуманное число. Документация: [Claude](https://code.claude.com/docs/en/headless), [Codex](https://learn.chatgpt.com/docs/non-interactive-mode).

CLI-подключение поддерживает текст и запросы инструментов Yuki. Для картинок и понимания снимка экрана выберите API-провайдер с поддержкой vision. В CLI-режиме ответ появляется после завершения генерации. Распознавание речи настраивается отдельно: подписка CLI не является ключом STT.

## Голос и локальный режим

Для голоса нужны три независимые части: распознавание, модель, озвучка. В настройках можно включить системный голос или поддерживаемый HTTP TTS. Качество системного голоса зависит от установленных в ОС языков и голосов.

Локальный STT требует уже запущенного сервера с OpenAI-совместимым `/v1/audio/transcriptions`. Указанный в интерфейсе localhost — адрес для настройки, а не обещание установленного сервера. Ollama и LM Studio сами по себе не распознают речь.

Начните с наушников: акустическое подавление эха при разговоре через динамики пока не проверено. Запись начинается после вашего действия. Постоянное прослушивание и обучение слова пробуждения включаются отдельно в настройках. Распознавание происходит после завершения фразы; streaming STT ещё нет.

## Основные действия

- Главная: разговор, микрофон, быстрые запросы, переключение включённых моделей.
- Чат: текст/голос, статусы инструментов, остановка ответа, новый разговор. Последний разговор сохраняется локально.
- Память: просмотр и редактирование разрешённых фактов о пользователе.
- Команды: последовательности действий и триггеры.
- Настройки → Интеграции → Возможности: MCP и локальные расширения; внешние серверы могут требовать отдельной установки/авторизации.
- Аватар: опциональная пользовательская VRM-модель. Чужие персонажи в дистрибутив не включены.

Опасные действия требуют подтверждения. Отмена останавливает дальнейшие шаги; уже выполненное внешнее действие не откатывается автоматически.

## macOS

Подготовлен сценарий сборки universal DMG для Apple Silicon и Intel в `.github/workflows/release.yml`. Его нужно запустить и проверить на macOS runner. Готового Mac-дистрибутива пока нет. Подпись Apple и notarization пока не настроены.

## Если что-то не работает

Проверьте точный текст ошибки, выбранную модель и страницу «Настройки». Для CLI проверьте вход и лимиты в терминале. Для микрофона проверьте разрешение ОС и отдельно конфигурацию STT. Диагностику можно экспортировать из настроек. Не отправляйте API-ключи в чат и не включайте их в отчёт.
