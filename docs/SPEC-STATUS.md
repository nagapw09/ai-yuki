# Сверка с ТЗ v2.0 — 17 сентября 2026

Это оценка реализации, а не обещание полного соответствия. Наличие кода и успешный модульный тест не заменяют проверку пользовательского сценария. Windows и macOS пока нельзя считать одинаково готовыми.

| Раздел ТЗ | Состояние | Что есть и что остаётся |
|---|---|---|
| 1–5. Архитектура и AI Agent | Реализовано на Windows, частично проверено | Tauri 2, React/TS, Rust, SQLite, агентный цикл и реестр инструментов. Agent Core написан на TypeScript вместо рекомендованного Python. Выполнение инструментов возвращает реальные результаты; конечный ответ всё ещё зависит от модели. |
| 2, 30. Windows / macOS | Windows собран; macOS не готов к выдаче | Есть адаптеры и Mac workflow. Нет проверенных Intel/Apple Silicon сборок, подписи и notarization. Нативное чтение accessibility на macOS не реализовано. |
| 4. Провайдеры | Реализовано, проверено не всё | API-адаптеры OpenAI, Claude, Gemini и совместимых сервисов, локальные endpoints. Claude Code и Codex используют официальный CLI и его вход. Текст и тестовое изображение проверены на обоих CLI. Нет общего доступа к лимитам всех аккаунтов; выбор модели не означает, что она доступна подписке. |
| 6. Управление компьютером | Частично проверено | Окна, ввод, буфер, снимки, OCR, Windows UI Automation. Исправлена COM-ошибка, нативное чтение окна Yuki проверено. Произвольные приложения, особенно Telegram, требуют проверки результата и не гарантируют доступность всех элементов через UIA. |
| 7, 26. Браузер / поиск | Частично | Открытие URL, управление вводом/UI, подключаемый Playwright MCP и поиск через интеграции. Нет подтверждённого полного набора браузерных сценариев на обеих ОС. |
| 8. Файлы и документы | Частично | Операции с файлами и локальные инструменты реализованы. Полноценный универсальный разбор PDF/DOCX/XLSX с OCR, chunking и ответами с источниками не завершён; некоторые форматы требуют интеграций. |
| 9. Память | Реализована основа | Локальное хранение, просмотр/изменение/удаление, подмешивание контекста, embeddings-слой. Полноценная проверенная эпизодическая память и автоматическое управление её качеством не готовы. |
| 10. Голос | Частично проверено | Захват, VAD, push-to-talk, STT adapters, TTS, локальные образцы wake word. Системный Windows TTS и амплитуда проверены. Живой микрофон/STT пользователя, echo cancellation и устойчивое перебивание не проверены. Настоящий streaming STT и задержка wake word <300 мс не подтверждены. CLI-подписка не заменяет STT-сервис. |
| 11. Личность | Реализовано | Имя, инструкции, характер и голос в профиле. Качество естественного общения зависит от модели и голоса. |
| 12. 3D-компаньон | Частично, доработка продолжается | VRM, смена персонажей, VRMA, прозрачное окно, перенос, click-through, моргание, выражения, рот по амплитуде Windows TTS. Библиотека и назначение готовых клипов. Самодельная хореография удалена. Сидение/ходьба/танцы из Unity-пакетов требуют конвертации: Unity пока отказал без активной лицензии Personal. Фонемный lip-sync не реализован. |
| 13–15. Интерфейс / чат | Реализовано, есть изменения относительно ТЗ | По последнему пожеланию пользователя вместо большого центрального Orb — полезная панель с мониторингом, погодой и напоминаниями. Ошибки и частичный ответ остаются в реплике, статусы раскрываются. Универсальные вложения через composer не завершены. |
| 16. Команды | Частично | Список с поиском, визуальное полотно, редактор шагов, шаблоны, запуск. Фраза/хоткей/startup/manual поддержаны. Все заявленные schedule/app-launched/webhook триггеры и комбинации логики не готовы. |

| 21–23. Разрешения / подтверждения / журнал | Реализована основа | Категории, gate, подтверждение высокого риска, журнал. Реальные отмена и запись проверялись. Сквозной аудит всех путей, особенно сторонних плагинов, не завершён. |
| 24. Контекст | Частично | Время/часовой пояс, окна, буфер, OCR, screenshot, системные сведения. «Текущий файл» и выделение зависят от приложения/интеграции. |

Приложение должно работать; после запуска пропущенные сроки обрабатываются. Произвольная recurrence, голос/звук уведомления и DST-календарное повторение не завершены. |
| 25. Календарь | Код есть, не проверено с аккаунтом | Google/Outlook OAuth и события. Нужны client IDs и реальный пользовательский вход; нельзя считать готовой интеграцией без проверки. |
| 27. Developer mode | Частично | Shell/интеграции и официальный CLI провайдера. Единый проверенный workflow Git/GitHub/Docker/IDE не завершён. |
| 28, 40. Telegram / удалённое управление | Частично | Отдельный экран, бот, код сопряжения, подтверждение на ПК, отзыв устройств, статус ошибок. Telegram Desktop управляется отдельно через UI-инструменты. Отправка файла в реальную группу не проверялась; root-agent не отправлял сообщения. Нет QR, мобильного клиента и полноценного gateway. |
| 29, 31. Локальные данные | Реализована основа | SQLite и OS secure storage для секретов. Local Only ограничивает облачный AI. История чата пока в localStorage и не включена полностью в SQLite backup. Нет cloud sync. |
| 32–33. Задачи и ошибки | Частично | Статусы шагов, отмена, безопасные повторы, сохранение ошибки. Нет полноценного устойчивого менеджера очередей с восстановлением всех длительных задач после краша. |
| 34. Проактивность | Не завершена | Есть локальный выбор занятия аватара. Проактивные предложения по рабочему контексту/календарю — отдельная будущая функция. |
| 35. Система / медиа | Частично | Живые CPU/RAM/GPU и место/чтение/запись дисков на Windows. Определение музыки через системные media sessions. Нет полной панели сети/батареи и всех медиакоманд/сервисов. |
| 36. Локализация | Частично | Базовый i18n есть. Новые экраны и часть старых строк пока на русском; полное RU/EN/UK покрытие не закончено. |

| 38–43. Полная готовность | Не достигнута | Нет основания объявлять весь исторический чек-лист выполненным. Приёмочные сценарии должны отдельно пройти на Windows и macOS. |

## Новые личные ассеты

- В библиотеке 6 VRM: Miku, Lulum, Arisa, AvatarSample_B, RadDollV3 и RadDollV3_Short.
- 7 готовых VRMA из исходного Motion Pack доступны для просмотра. Приветствие использует стоячую часть исходного клипа и не проигрывается обратно.
- Из архивов выделено 144 `.anim` и один FBX; скрипты из чужих Unity-пакетов не запускались.
- 54 непустых клипа мимики Shinano / リア-アリス проверены по именам morph targets: ни один не совместим полностью с шестью имеющимися VRM. Это не универсальные эмоции; подмена неизвестных morph targets не выполнялась.
- Scarlet и Rosetta предоставлены в `.blend`; Resonite — в собственном формате. Они пока не импортированы как рабочие VRM. `V_Camera` содержит камерные VMD, а не движения тела.
- Личные модели/движения не включаются в распространяемый установщик.
