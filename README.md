# Yuki 0.2

Персональный голосовой компаньон для Windows и macOS: разговор, память, работа с компьютером и команды. Основа — Tauri 2, React, TypeScript и Rust.

Проект перенесён из `D:\github\ai-yuki` в отдельную рабочую папку. Старый проект и его данные не изменены. Новый идентификатор приложения: `ai.yuki.companion`.

## Что изменилось

- Новый орбитальный главный экран и боковая навигация.
- Claude Code и Codex через официальный CLI с сохранённым входом, без копирования OAuth-токенов; остаются API-провайдеры и локальные модели.
- Отдельная настройка распознавания речи в мастере первого запуска.
- Работающий микрофон в чате, отмена запросов и остановка последующих действий.
- Локальное сохранение последнего разговора.
- Сборка Windows NSIS и конфигурация macOS universal DMG.

## Запуск

[Инструкция первого запуска](docs/QUICKSTART-RU.md) описывает ключи, подписки CLI и голос. Windows-установщик создаётся в `target/release/bundle/nsis/`. Для CLI нужен установленный и авторизованный официальный клиент. Для распознавания речи нужен отдельный STT-сервис или сохранённый OpenAI API-ключ; подписка на текстовую модель не заменяет STT.

## Состояние работы

Текущие результаты проверки и незавершённые задачи: [HANDOFF.md](HANDOFF.md). Не считать исторические отметки в старых ROADMAP/GAPS подтверждением тестирования этого выпуска. macOS-дистрибутив требует сборки и проверки на Mac; Windows-машина его не заменяет.

Проверены 111 TypeScript-тестов и 288 Rust-тестов, реальные ответы через Claude Code и Codex. В нативном Windows-приложении проверены вход Claude, диалог с вызовом системного инструмента, запись тестового файла, отказ от перезаписи, остановка CLI-запроса и системная озвучка. Голос с реальным STT-ключом и Mac пока не проверены. Подробности: [VALIDATION.md](docs/VALIDATION.md).

## Разработка

Нужны Node.js 22+, Rust stable и [зависимости Tauri](https://v2.tauri.app/start/prerequisites/).

```sh
npm ci
npm run typecheck
npm test
cargo test --workspace --lib
npm run tauri:dev
```

Сборка Windows из `apps/desktop`:

```sh
npm run tauri:build -- --bundles nsis --ci
```

На macOS установите Rust targets `aarch64-apple-darwin` и `x86_64-apple-darwin`, затем из `apps/desktop`:

```sh
npm run tauri:build -- --target universal-apple-darwin --bundles dmg --ci
```

Workflow GitHub Actions сохраняет файлы как artifacts, автоматически ничего не публикует. Автообновления и подпись дистрибутивов пока не настроены.
